# ASCII//RAIN Roadmap

## v0.1 — Visual proof — DONE
Third-person movement, shooting, ASCII renderer, procedural city arena, enemy director and early XP upgrades.

## v0.2 — Roguelike loop — DONE
Five enemy archetypes, elites, relics, caches, teleporter event, WATCHER boss and ASCII death FX.

## v0.3 — Reality Fragment — DONE
Far-future digitized-world premise, Reality Archive, first non-encoded artifact, persistent story progression and Android controls.

## v0.4 — Animation Pass — DONE
Procedural articulated survivor/enemy animation, locomotion, recoil, landing, dash motion and boss animation.

## v0.5 — Combat + City Pass — DONE
- three weapon modes;
- stronger hit feedback and camera response;
- stagger / knockback;
- ASCII impact / melee / dash FX;
- brighter readable night lighting;
- denser procedural street detail;
- more differentiated enemy silhouettes;
- Android-aware dynamic-light budget.

## v0.6 — Architecture Foundation — CURRENT
- data-driven weapons, enemies and item catalog;
- WeaponController + InventoryComponent;
- event bus, runtime profile and pooling services;
- projectile/tracer pooling;
- formal code standard + expanded validation;
- incremental path away from monolithic gameplay scripts.

## v0.7 — Polished vertical run
- polish one complete 10–15 minute run before adding a second district;
- clearer enemy attack telegraphs;
- damage indicators and status readability;
- stronger teleporter climax;
- one additional WATCHER pattern or phase;
- audio event hooks / music intensity states;
- first intentionally staged Reality Fragment encounter;
- actual PC + Android profiler measurements and targeted optimization.

## v0.8 — District system
Chunk-based city layouts, navigation-aware encounter spaces, stage transitions and persistent run state.

## Later
More survivors, weapon kits, artifacts, bosses, districts, meta unlocks, logs and narrative fragments. Keep the world ASCII-encoded; ordinary 3D remains rare and story-significant.
