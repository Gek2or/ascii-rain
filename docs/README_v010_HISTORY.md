# ASCII//RAIN v0.10 — Run Loop

Полный Godot-проект на базе v0.9.2 Render Fix. **Это исходники, не APK/EXE.**
Мир, оружие, музыка, ASCII-атласы и параметры читаемости сохранены.

## Запуск

Распакуйте ZIP в **новую папку**, в Godot выберите **Import → project.godot**,
затем **F5**. Основная сцена: `scenes/Main.tscn`. Старые рабочие версии не удаляйте.
В ZIP сохранены явные записи папок перед файлами. Никаких SDK или шрифтов
в архиве нет; для обычного запуска исходников .NET не требуется.

Графические настройки v0.9.2 не сбрасываются. ESC / SET открывает прежнее меню;
PREVIEW оставляет игру на паузе. F1 — отладочное выключение ASCII.

## Первый забег

1. Найдите золотой маркер **STARTER CACHE**. Подойдите и нажмите **E / USE**.
   Бесплатно выберите один предмет: Chain Arc, Split Core или Leech Wire.
2. Посетите **два разных района** в любом порядке. Повторное посещение не
   засчитывается второй раз. Исследование остальных районов остаётся свободным.
3. Следуйте к **TELEPORTER** и активируйте его. Находитесь в поле зарядки и
   победите WATCHER. Вне поля зарядка приостанавливается, не обнуляется.
4. После победы и полной зарядки оставшиеся враги удаляются **без награды**,
   новые группы не появляются. Изучите настоящую деревянную игрушку — это
   **необязательная** находка; можно сразу уйти через телепортер.
5. Войдите в телепортер: итог забега показывает районы, сундуки, предметы,
   убийства и новые записи архива. RESTART начинает новый забег.

Боевые предметы/кредиты не сохраняются между забегами. Настройки и **Reality
Archive** сохраняются. Уже найденная игрушка не становится недоступной
обязательной целью в следующем забеге.

## Сундуки: выбор одного из трёх

Бой, движение и таймер приостановлены на время выбора. ПК: мышь либо **1/2/3**;
Android: кнопки-карточки. **Cancel / Esc** ничего не списывает. Варианты
при повторном открытии того же сундука не меняются. Цена списывается один раз,
только при получении выбранного предмета. Предметы с максимальным стаком
исключаются. Повторные нажатия не дают двойной награды.

После закрытия меню краткая защита от случайного выстрела: отпустите FIRE/LMB
и нажмите вновь. Настройки и осмотр артефакта не открываются поверх выбора.

## Управление

ПК: WASD — движение, мышь — камера, LMB — огонь, RMB — точное наведение,
Space — прыжок, Shift — dash, E — взаимодействие, Q / 1–3 — оружие,
Esc — настройки. Во время выбора 1–3 относятся к карточкам, не к оружию.

Android: левый аналоговый стик — движение; FIRE с перетаскиванием — огонь и
камера одним пальцем; AIM — точное наведение; JUMP, DASH, USE, WPN, SET.
TEST COURTYARD в настройках — отдельная лаборатория, вход завершает текущий
забег; RETURN TO CITY начинает новый. Архив не стирается.

## Что реально проверено

В этой версии выполнены не только Python-проверки, но и **native Godot tests**:
- машина прогресса, выбор/лимиты предметов;
- Main, сундуки, заморозка времени, отмена/подтверждение, реальные сигналы GUI;
- детектор районов, физические проверки места появления врагов, блокировка
  взаимодействия стеной, телепортер, WATCHER phase 2, артефакт, выход и рестарт;
- движение, стрельба, меню и синтетический двухпальцевый ввод;
- реальная отрисовка Main и окна выбора через Godot OpenGL/программную Mesa.

**Условия:** Linux debug export template Godot `4.8.dev.mono.gh.3756fbb2c`,
без включённого C# в проекте. Временная QA-копия использует ресурсы
ImageTexture/AudioStreamWAV, подготовленные native API, вместо редакторского
импорта PNG/WAV. Это **не проверка импортёра редактора** и не подтверждение
производительности телефона. Windows/Android export, реальные касания,
визуальная оценка на устройствах и длительный балансный плейтест не выполнены.

См. `docs/BUILD_STATUS.md`, `docs/NATIVE_TESTING_v0_10.md`, логи в `build/`.
Кадры в `build/captures/` — настоящий тестовый запуск, не концепт-арт.

## Повторение проверок

Обычный редактор (на своей машине):

```sh
python tools/run_engine_checks.py --godot /path/to/godot
```

Резервный QA-путь для доверенного Linux debug template:

```sh
python tools/run_debug_template_checks.py --template /path/to/template
# Добавьте --render только с доступным графическим DISPLAY.
```

Оба сценария изолируют пользовательские сохранения. Интеграционный тест
намеренно сохраняет тестовую игрушку и потому требует `--test-isolated`.
Не запускайте его вручную в своём обычном профиле.
