# ASCII//RAIN v0.10.1 — Visual Balance

Полный исходный Godot-проект на базе v0.10 Run Loop. Это НЕ APK / EXE.

## Запуск
Распакуйте ZIP в новую папку. Import -> выберите распакованный `project.godot` -> F5.
Старую рабочую папку не удаляйте. Исправленная упаковка с записями папок сохранена.
Настройки v0.10 и постоянный архив артефактов НЕ сбрасываются и не мигрируют заново.
Новый фильтр работает и с сохранёнными параметрами. Для чистого сравнения доступна
кнопка `ESC / SET -> RESTORE READABLE NIGHT`, ширина символа 6 на ПК (8 на Android).
`PREVIEW` прячет панель, сохраняя паузу. F1 переключает ASCII для отладки.

## Что исправлено
- Тёмные поверхности больше не выбирают плотные Y/L/T/K из середины алфавита.
- Палитра яркости: пробел, точка, двоеточие, тире, плюс, равно, звёздочка, #, @.
- Плавный переход между соседними масками; нет случайной подстановки букв или TIME.
- Ограниченный контраст штрихов: убрано деление яркости на малую площадь символа.
- Фон клетки сохраняет тон поверхности; это один цвет на клетку, не подмешанный
  полноразмерный 3D-кадр. ASCII остаётся способом отображения мира.
- Снижено влияние тумана на небо, но не общее освещение улиц.
- У героя снова различаются материалы оружия, корпуса и ботинок; прежний единый
  светлый минимум заменён ограниченным преобразованием исходного материала.
- Текст HUD получил тёмную обводку и на ПК. Меню обозначает версию 0.10.1.

## Проверки
79 Python-проверок исходников и данных; native Godot: 73 проверки состояния забега,
42 проверки интеграции, движение/стрельба/меню и синтетический мультитач.
126 дополнительных проверок реальных пикселей CanvasItem в Godot (ширины 4–10):
монотонность яркости, видимые полутона, ограничение яркости штрихов, снижение
контраста на плоском фоне и отсутствие изменения кадра при неподвижном входе.
Скриншоты из движка: `build/captures/`. Это не сгенерированный концепт.

Среда: Godot 4.8 dev Linux debug export template, Compatibility, Mesa llvmpipe.

стабильные Godot на Windows/Android, физический сенсорный экран, APK/EXE и
аппаратная производительность здесь не проверялись. Полного совпадения с
художественным референсом пока нет; геометрия и анимация остаются прототипными.
