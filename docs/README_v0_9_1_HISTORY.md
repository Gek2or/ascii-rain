# ASCII//RAIN v0.9.1 — Mobile Clarity

Полный исходный Godot-проект, продолжение **v0.9 Readability & Motion**.
Это **не APK и не EXE**. Основная сцена по-прежнему `scenes/Main.tscn`.

## Запуск

Распакуйте в отдельную папку и импортируйте `project.godot` в редактор Godot,
в котором уже запускается v0.9. Дождитесь импорта ресурсов, затем запустите проект.
В Android-редакторе можно запускать сцену непосредственно, без экспорта APK.

Сначала откройте **SET / ESC → Restore v0.9.1 clarity defaults**. Старые
сохранённые настройки не удаляются автоматически; этот пункт применяет новый
набор значений читаемости. Он не очищает Reality Archive и не сбрасывает звук.
На Android контуры глубины после сброса выключены. Основной ASCII-фильтр,
подсветка персонажей и новая обработка фона работают независимо от них.

## Что изменилось

### Читаемость и обратная связь

Плотность символов и яркость теперь регулируются раздельно: ровная стена или
земля получают менее плотное заполнение, а границы формы и яркие источники
сохраняют детализацию. Настройки **Calm flat backgrounds** и **World color
saturation** независимы от качества. Атлас остаётся 32-символьным; случайного
мерцания в фильтре не добавлено. Подсветка героя и врагов скорректирована без
отключения проверки глубины — персонажи не видны сквозь стены.

Вместо красной заливки всего экрана урон вызывает короткую вспышку по краям.
Центральная область остаётся незакрашенной. Затухание длится 220 мс реального
времени и не растягивается вместе с замедлением при сильном попадании.

### Управление Android

Круглый аналоговый стик слева; справа FIRE, AIM, JUMP, DASH, USE, WPN. Удерживая
**FIRE**, можно тем же пальцем вести камеру. Второй палец при этом управляет
движением. **AIM** — переключатель уменьшенной чувствительности, а не автоприцел.
Для DASH отображается оставшееся время перезарядки. Размер кнопок и
чувствительность касания настраиваются отдельно.

При паузе, смерти, потере фокуса, смене сцены или изменении настроек удержания
сбрасываются. Эмуляция мыши сохраняется для обычных кнопок меню, но мышиные
привязки стрельбы на мобильной платформе отфильтрованы по физическому устройству:
касание стика не должно одновременно означать выстрел левой кнопкой мыши.

Здоровье, опыт и сведения об оружии перенесены выше, за пределы зон больших
пальцев. Большая панель предметов на Android скрыта; список доступен в
**SET → CURRENT RELICS**. На ПК нижний HUD сохранён.

### Стрельба возле препятствий

Проверяются луч камеры, участок от плеча до дула и линия от дула к цели. Если
дуло оказалось за углом/в стене, попадание останавливается у препятствия, а не
проходит сквозь него. Заблокированная линия отмечается оранжевым индикатором.
Плечевое смещение перенесено на SpringArm3D, чтобы его проверка столкновений
соответствовала положению камеры. Процедурная анимация v0.9 сохранена.

## TEST COURTYARD

Открывается через **SET / ESC → TEST COURTYARD (ends current run)**.
**Переход завершает текущий забег. RETURN TO CITY начинает новый.**
Постоянный архив артефактов не удаляется и не пополняется в тестовом дворе.

В дворе три неподвижные возрождающиеся мишени, тёмная стена, яркие окна,
среднетоновая стена, угловое и низкое укрытия, пандус с площадкой. Здесь нет
директора волн или босса. Можно проверить прицел, ходьбу, стрельбу и видимость
без боя. Кнопка **TEST HIT FLASH** показывает новую индикацию урона; на ПК
её вызывает **F6**, когда мышь захвачена игрой.

**Show FPS and frame-time overlay** выводит FPS и время кадров за окно до
120 отсчётов, включая P95. Это диагностический индикатор в текущей сцене,
не GPU-профилировщик и не опубликованный замер производительности.

## Сохранено из предыдущей версии

Большой город с районами и посещением локаций, три оружия, пять обычных
архетипов врагов, элиты, сундуки, двенадцать предметов, WATCHER, музыка,
сенсорная поддержка, телепортер и Reality Archive. Музыкальный файл, оба
утверждённых референса, данные предметов/врагов/оружий и сюжетный код сохранены.

Мир остаётся оцифрованным ASCII-миром. Только чрезвычайно редкие настоящие
артефакты представлены без фильтра в отдельном просмотре. Мир не превращается
постепенно в обычный 3D. Источник сюжетного ТЗ — `docs/STORY_BIBLE_v0_3.md`.

## Проверки и ограничения

В этой среде выполнены статические проверки ссылок/сцен/входных действий,
проверка исходников и **42 Python-теста** (контракты исходников и численные
эталонные расчёты). Это не исполнение GDScript.

**Godot import/parser, Play Mode, компиляция GPU-шейдеров и Android/Windows
экспорт этой версии здесь не запускались**: исполняемый файл движка недоступен.
Подтверждённый пользователем запуск относится к базовой v0.9, не к этому ZIP.
Сведения: `docs/BUILD_STATUS.md`, `build/validation_report.json`.

Для среды с установленным Godot:

```sh
python tools/static_gdscript_guard.py
python tools/validate_project.py
python -m unittest discover -s tests -p 'test_*.py' -v
python tools/run_engine_checks.py --godot /path/to/Godot
```

Последняя команда запускает реальный импорт и два GDScript-теста с временной
папкой сохранений. При отсутствии движка возвращает **NOT RUN / код 2**, а не
успех. Headless-проверки тоже не заменяют тест GPU и сенсорного управления.

Для ручного показа мобильного интерфейса на ПК: `godot --path . -- --touch-preview`.
Он включает мобильные настройки и интерфейс; сам по себе не превращает
обычную мышь в мультитач. Для теста двух пальцев нужно сенсорное устройство.

В этой версии не добавлены новая анимационная система, следующий биом,
переход между главами или полный новый забег на 15 минут. Их разработка
следует после проверки управления и читаемости на устройстве.
