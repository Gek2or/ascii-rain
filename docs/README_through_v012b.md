# ASCII//RAIN v0.12b — Archive Stacks & Memory Gardens

**Полный Godot-проект с исходниками, не APK / EXE. Второй этап Living City.**

Два района переработаны внутри существующего города. Рынок и транспортный узел
v0.12a остаются. ASCII-шейдер, его атласы, управление, анимация героя, музыка,
боевые предметы, сюжет и пути сохранений не заменены.

## Открыть

Извлеките весь ZIP в **новую папку**, импортируйте извлечённый `project.godot`, F5.
Для работы в редакторе обычные PNG/WAV должны закончить первый импорт.
Сбрасывать графику не нужно. Старые рабочие папки не удаляйте.

**ПК:** WASD, мышь, ЛКМ — огонь, ПКМ — точное наведение, Space — прыжок,
Shift — dash, E — взаимодействие, Q / 1–2–3 — оружие, Esc — меню.
**Android:** левый аналоговый стик, правый обзор, FIRE + движение пальцем,
AIM, JUMP, DASH, USE, WPN, SET. Экспортный пресет не является готовым APK.

## Найти новые районы

После бесплатного STARTER CACHE можно выбрать любые два района. Теперь:

- **ARCHIVE // STACKS**: северо-восток города. Вход `(51, 0, 4)`, центр
  `(51, 0, -24)`. Двор, архивные башни, две галереи +5,5 м и два поперечных
  моста. Пандусы вдоль боковых галерей; проход под мостами настоящий.
- **MEMORY // GARDENS**: юго-запад. Вход `(-43, 0, 24)`. Улица, заполненная
  терраса +2,75 м, павильон +5,5 м. Два подъёма на нижнюю террасу, связь
  террасы с павильоном и отдельный пандус с улицы к павильону. Можно
  пройти круг без обязательного прыжка. Под павильоном есть нижний проход.

ARCHIVE ROW сохраняет прежний внутренний ID; отображаемое имя уточнено.
Этажи не считаются разными районами и не обнуляют угрозу. Подъём противника
происходит по настоящему маршруту, не телепортацией.

Четыре прежних сундука размещены в новых локациях: архивный двор/галерея,
нижняя садовая терраса/павильон. **Общее число сундуков — прежние 14.**
После исследования остаётся прежний телепортер → WATCHER → артефакт → выход.

## Живость и звук

Над архивами медленно движется курьер картотеки; табло реагирует на локальную
угрозу и возвращается к работе. В садах вращается поливочный механизм.
Сервисный дрон и дальний поезд из рынка/транспорта сохранены.

**ESC / SET → CITY AMBIENCE**:

- `Ambient motion` — движение окружения; 0 выключает движущиеся украшения,
  не удаляя ни маршруты, ни укрытия. Курьер скрыт на Low и вдали от архивов.
- `District ambience` — отдельная громкость двух новых позиционных фоновых
  петель: архивная вентиляция/реле и садовый дождь/капли. На них также влияет
  SFX. Во время местной угрозы фон становится тише. Музыка не заменена.

Фоновое окружение не спавнит врагов, не выдаёт наград и останавливается при паузе.
Настройки сохраняются отдельно от графики. Новые звуки синтезированы специально
для проекта; внешние записи, голоса и лицензируемые сэмплы не использованы.

## Что здесь НЕ заявляется

Это этап **b**, не весь законченный город. Подземный Utility Depths, связанная
сеть крыш и лифты — последующие задачи. Нет нового героя, новых типов врагов,
нового саундтрека или переделанного ASCII-фильтра. Сады и архивы остаются ASCII;
обычные деревья и механизмы не являются настоящими сюжетными артефактами.

Воспроизводимые тесты выполняются нативно в Linux Godot **4.8 dev debug template**
с временной подготовкой PNG/WAV. Это **не обычный импорт стабильным редактором**
и не испытание физического Windows/Android, сенсорного экрана или скорости GPU.
Точные результаты и ограничения: `build/BUILD_STATUS.txt`, `docs/BUILD_STATUS.md`.

В `build/captures/` — настоящие кадры этой версии с постановочными камерами.
Кадры с суффиксом `_raw` сняты с отключённым ASCII для проверки геометрии.
Medium/8px — настройка на том же Linux-стенде, не мобильный скриншот.
`reference/` содержит утверждённые концепты, а не кадры игры.

Подробности: `docs/ARCHIVES_GARDENS_v0_12b.md`.
История: `docs/README_v0_12a_HISTORY.md` и `CHANGELOG.md`.
