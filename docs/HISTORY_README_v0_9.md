# ASCII//RAIN v0.9 — Readability & Motion

Полный исходный Godot-проект, продолжение **v0.8.1**, не новая игра с нуля.
Целевые платформы: ПК и Android. Базовый renderer: Compatibility.

## Запуск

Распаковать ZIP в отдельную папку, импортировать `project.godot`, запустить проект через F6/F5 (основная сцена `scenes/Main.tscn`). Базовый проект использует API Godot 4.3+. Совместимость этой версии с конкретным редактором и устройством требует запуска; движок здесь не исполнялся.

**Это исходный проект, не APK/EXE.** Пресеты экспорта обновлены до 0.9.0. Для бинарного экспорта нужны соответствующие шаблоны Godot и Android SDK для Android.

## Первое сравнение

Открыть ESC / SET → `Restore v0.9 readability defaults`. Старые пользовательские настройки остаются в `user://ascii_rain_settings.cfg`, поэтому эта кнопка позволяет сравнивать изменения с новыми значениями. F1 переключает обычную 3D-картинку и ASCII. История и музыка сохраняются.

## Изменения

### Читаемость

Исправлено фоновое освещение: раньше сцена запрашивала Sky-освещение без Sky. Теперь используется цветовой ambient и более читаемые материалы улиц. Переработано отображение средних тонов в ASCII: новый атлас из 32 вручную нарисованных символов, прямоугольная сетка, усреднение внутри клетки и умеренное сохранение тонких ярких объектов. Убрано несколько конфликтовавших старых параметров шейдера.

У героя и обычных врагов — освещаемая броня с разной контровой подсветкой. Светящиеся ядра и телеграфы не заменены материалом брони. Дополнительный отключаемый depth-contour pass использует глубину того же viewport, а затем сам проходит через ASCII. Отдельный экранный буфер нормалей не используется: нет зависимости от Forward+ для этой функции.

**Depth contours не проверены на GPU.** На Android они по умолчанию отключены. При артефактах отключить этот пункт, остальные изменения читаемости останутся.

### Герой и управление

Пересобраны пропорции тела и коллизии: в исходной модели ноги заходили под пол. У конечностей теперь скруглённая геометрия. Добавлены аналитическая двухзвенная постановка ног, опрос высоты пола на физических кадрах, фазы опоры/переноса, сгибание коленей, привязка рук к точкам хвата оружия. Это процедурный articulated-mesh rig, **не motion capture и не финальная skeletal-анимация**.

Шаг следует пройденному расстоянию. Поворот тела сглажен относительно камеры. Камера менее навязчива, её движение регулируется отдельно; правой кнопкой мыши можно стабилизировать прицеливание. Аналоговый стик больше не нормализует любое отклонение до полной скорости. Прицел получил тёмную подложку и скрывается во время паузы/после смерти.

### Город

Площадь 164×164 сохранена. Добавлены рамы входов, козырьки, карнизы, вентиляционные решётки, трубы, сервисные ящики, решётки стоков и две остановочные конструкции. Новая мелкая геометрия сгруппирована через MultiMesh по материалу и ячейкам 24 м. Дальность её видимости зависит от качества.

В точке **(-28, 0, -42)** добавлен сервисный настил высотой 2 м с двумя пологими пандусами и реальной коллизией. Это один тестовый элемент вертикальности, а не полноценная система доступных крыш/интерьеров. Столкновения мелкого декоративного обвеса намеренно не добавлены.

### Встречи

Исправлен таймер первой группы, который раньше требовал точного попадания в 0.0. Вход в район запускает задержку 2.6 сек после стартового спокойного периода. Уход из района отменяет отложенную первую волну. Очки угрозы накапливаются только в текущем районе, ограничены сверху; между группами остаются паузы. Обычные враги возвращаются к месту появления, если герой далеко уходит. Событие телепортера работает отдельно.

### Настройки

Сохраняются независимо: средние тона, контровая подсветка актёров, depth contours, интенсивность движения камеры. Меню прокручивается, значения показаны числами, RESUME остаётся вне прокрутки. Синхронизация контролов не вызывает повторных обработчиков сохранения. Музыка и SFX из v0.8.1 сохранены.

## Управление

WASD — движение; мышь — обзор; ЛКМ — огонь; ПКМ — стабилизация прицеливания; Space — прыжок; Shift — рывок; Q / 1–3 — оружие; E — взаимодействие; ESC — настройки; F1 — ASCII/3D. Сенсорные MOVE/LOOK/FIRE/JUMP/DASH/USE/WPN/SET сохранены.

## Сюжетное правило

Оцифрованный мир далёкого будущего **не превращается постепенно в обычный 3D**. Только редкие артефакты показываются без ASCII в отдельном окне изучения. Сохранены Reality Archive, фотография, деревянная игрушка и `docs/STORY_BIBLE_v0_3.md`. Утверждённые изображения лежат в `reference/`; они — художественная цель, не скриншоты этой версии.

## Проверки

Результаты — `docs/BUILD_STATUS.md` и `build/source_tests.log`. Статические проверки и 19 Python-тестов проверяют связи, настройки, геометрию покоя и отдельные математические модели. **Они не исполняют GDScript и не заменяют Godot.**

`tools/run_engine_checks.py --godot /path/to/godot` запускает настоящий импорт и headless smoke test в изолированной папке сохранений. Этот сценарий включён в проект, но здесь не выполнен. Он тоже не проверяет GPU-шэйдеры, реальные FPS, Android touch и качество анимации в кадре.
